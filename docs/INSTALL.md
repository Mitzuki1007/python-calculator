# Инструкция по установке Python Calculator

## 1. Предварительные требования

Необходимое программное обеспечение:

- Операционная система Windows 11.
- Установленный Python 3.
- Git для получения проекта из удалённого репозитория.
- Доступ к интернету для клонирования репозитория.

Сторонние библиотеки для запуска программы устанавливать не требуется.

## 2. Проверка наличия Python и Git

Перед началом установки необходимо убедиться, что Python и Git доступны в командной строке.

### Проверка Python

Откройте PowerShell или терминал Visual Studio Code и выполните:

```powershell
python --version
```

В ответ должна отобразиться установленная версия Python, например:
Python 3.x.x.
Если команда не распознаётся, необходимо установить Python с официального сайта.

### Проверка Git

Выполните команду:

```powershell
git --version
```
Если Git установлен, появится информация о его версии.
Если команда не распознаётся, скачайте Git с официального сайта.

## 3. Получение проекта

Проект размещён на GitHub:

https://github.com/Mitzuki1007/python-calculator

Для получения проекта необходимо:

1. Открыть PowerShell или терминал.
2. Перейти в папку, в которой будет храниться проект.
3. Выполнить команду:

```powershell
git clone https://github.com/Mitzuki1007/python-calculator.git
```

После завершения загрузки появится папка `python-calculator`.

## 4. Переход в папку проекта

Для перехода в папку загруженного проекта выполните:

```powershell
cd python-calculator
```

## 5. Установка зависимостей

Данный проект не требует установки сторонних Python-библиотек.

В программе используются стандартные модули Python, в том числе:

- `math` — математические функции и вычисления.
- `unittest` — создание и запуск автоматических тестов.
- `unittest.mock` — подмена пользовательского ввода и проверка вывода при тестировании.
- `io` — работа с потоками ввода-вывода в тестах.

Эти модули входят в стандартную библиотеку Python.

## 6. Запуск программы

Для запуска калькулятора убедитесь, что терминал находится в корневой папке проекта.

Выполните команду:

```powershell
python main.py
```

## 7. Проверка правильности работы программы

Для проверки программы выполните несколько действий.

### Проверка сложения

1. Запустите программу.
2. Выберите пункт меню 1.
3. Введите первое число 2.
4. Введите второе число 3.

*Ожидаемый результат:* 5

### Проверка справочной информации

1. Выберите пункт меню 6.
2. Убедитесь, что появилась справочная информация.
3. Проверьте, что после её отображения программа возвращается к главному меню.

### Проверка неправильного ввода

1. В главном меню введите 9.
2. Убедитесь, что программа сообщает об ошибочном выборе и показывает меню повторно.

### Проверка автоматических тестов

Для проверки основных функций программы выполните:

```powershell
python -m unittest -v
```

При успешном выполнении автоматические тесты завершаются результатом **OK**.

## 8. Возможные проблемы и способы их устранения

### Проблема 1. Команда python не распознаётся

**Причина:** Python не установлен или не добавлен в переменную PATH.

**Решение:**

1. Установить Python с официального сайта.
2. При установке включить параметр Add Python to PATH.
3. Перезапустить терминал.
4. Повторно выполнить `python --version`.

В качестве альтернативы можно попробовать команду:

```powershell
py --version
```

### Проблема 2. Команда git не распознаётся

**Причина:** Git не установлен или отсутствует в переменной PATH.

**Решение:**

1. Скачать и установить Git.
2. Завершить установку.
3. Перезапустить терминал.
4. Проверить Git командой `git --version`.

### Проблема 3. Не удаётся найти файл main.py

**Причина:** терминал открыт не в корневой папке проекта.

**Решение:**

Перейти в папку проекта:

```powershell
cd python-calculator
```

Проверить наличие файла:

```powershell
dir
```

После этого повторить команду запуска:

```powershell
python main.py
```
