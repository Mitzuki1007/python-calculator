# Python Calculator

## Документация проекта

Добро пожаловать на страницу документации Python Calculator!

Python Calculator — консольный калькулятор на языке Python, предназначенный для выполнения основных математических операций.

## Возможности программы

- Сложение двух чисел.
- Вычитание двух чисел.
- Умножение двух чисел.
- Деление с проверкой деления на ноль.
- Вычисление среднего арифметического.
- Обработка неправильного ввода.
- Отображение справочной информации.
