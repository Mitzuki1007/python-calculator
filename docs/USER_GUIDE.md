# Руководство пользователя Python Calculator

## 1. Назначение программы

Python Calculator — консольный калькулятор, предназначенный для выполнения основных математических операций. Программа позволяет складывать, вычитать, умножать и делить числа, вычислять среднее арифметическое списка значений.

## 2. Взаимодействие с программой

Для начала работы необходимо запустить калькулятор командой:

```bash
python main.py
```

После запуска появится главное меню:

```text
========== КАЛЬКУЛЯТОР ==========
1. Сложение
2. Вычитание
3. Умножение
4. Деление
5. Среднее арифметическое
6. Помощь
0. Выход
=================================
```

Для выполнения операции необходимо ввести соответствующий номер и нажать Enter.

При выборе математической операции программа запрашивает необходимые числа, выполняет вычисление и отображает результат.

## 3. Сценарии использования программы

### Сценарий 1. Сложение двух чисел

**Исходные условия:** калькулятор запущен, пользователь находится в главном меню.

**Действия:**

1. Выбрать пункт 1.
2. Ввести первое число 2.
3. Ввести второе число 3.

*Ожидаемый результат:* 5.0

После вычисления программа возвращается к главному меню.

### Сценарий 2. Вычисление среднего арифметического

**Исходные условия:** программа запущена и отображает главное меню.

**Действия:**

1. Выбрать пункт 5.
2. Ввести числа через пробел: 2 4 6.

*Ожидаемый результат:* 4.0


Программа вычисляет среднее значение и снова отображает меню.

Для ввода списка также можно использовать запятые или точки с запятой.

### Сценарий 3. Использование справочной информации

**Исходные условия:** программа запущена и отображает главное меню.

**Действия:**

1. Ввести 6.
2. Дождаться отображения справочной информации.
3. Ознакомиться с описанием доступных операций.

*Ожидаемый результат:* Программа отображает описание математических операций и способов работы с калькулятором, после чего возвращается к главному меню.

## 6. Распространённые ошибки пользователя

### Ошибка 1. Неправильный пункт меню

**Причина:** пользователь вводит номер, которого нет среди доступных пунктов меню.

**Пример:** ввод числа `9`.

**Сообщение программы:**

```text
Ошибка: такого пункта меню нет. Выберите пункт от 0 до 6.
```

**Решение:** повторно выберите существующий пункт меню от 0 до 6.

### Ошибка 2. Попытка деления на ноль

**Причина:** пользователь вводит ноль в качестве второго числа при делении.

**Сообщение программы:**

```text
Ошибка: Делить на ноль нельзя.
```

**Решение:** повторите операцию, указав ненулевой делитель.
