# Инструкция по тестированию Python Calculator

## 1. Какие функции проверяются

В проекте проверяются следующие возможности:

- Сложение двух чисел.
- Вычитание двух чисел.
- Умножение двух чисел.
- Деление двух чисел.
- Обработка попытки деления на ноль.
- Вычисление среднего арифметического списка чисел.
- Обработка пустого списка.
- Вычисление среднего арифметического одного числа.
- Отображение справочной информации.
- Обработка неправильного выбора пункта меню.

## 2. Запуск автоматических тестов

Перед запуском тестирования необходимо открыть терминал в корневой папке проекта.

Для проверки синтаксиса файлов выполните:

```bash
python -m py_compile main.py test_main.py
```

Для запуска автоматических тестов выполните:

```bash
python -m unittest -v
```

## 3. Ожидаемые результаты при успешном выполнении тестов

Проверка синтаксиса ничего не отображает при успешном выполнении.

Пример результата при выполнении автоматических тестов:


## 4. Действия при ошибках тестирования

Если тест завершился ошибкой, необходимо изучить сообщение, которое вывел Python.

### Ошибка ImportError

**Причина:** программа или тесты используют неправильные названия функций либо файл `main.py` недоступен для импорта.

**Решение:** проверить импорты в файле `test_main.py` и соответствие названий функций в `main.py`.

### Ошибка SyntaxError или IndentationError

**Причина:** нарушение синтаксиса Python или неправильные отступы.

**Решение:** открыть файл и исправить участок, указанный в сообщении об ошибке. Затем повторно выполнить проверку синтаксиса.

### Ошибка AssertionError

**Причина:** фактический результат работы функции не совпадает с ожидаемым результатом теста.

**Решение:** проверить исходный код функции, входные данные и правильность ожидаемого результата.

После исправления необходимо повторно запустить автоматические тесты.

## 5. Примеры тестовых случаев

| Входные данные | Ожидаемый результат | Фактический результат |
|---|---|---|
| addition(2, 3) | 5 | 5.0 |
| arithmetic_mean([2, 4, 6]) | 4 | 4.0 |
| division(10, 0) | Исключение ZeroDivisionError | Ошибка: Делить на 0 нельзя |
| Выбор пункта меню 9 | Сообщение о неправильном выборе | Ошибка: такого пункта меню нет. Выберите пункт от 0 до 6. |
