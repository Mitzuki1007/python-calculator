
# Python Calculator

## 1. Название + описание

**Python Calculator** — консольный калькулятор, разработанный на языке Python. Программа предназначена для выполнения основных математических операций и расчётов с использованием текстового меню.

## 2. Возможности программы

Калькулятор предоставляет следующие возможности:

- Сложение двух чисел.
- Вычитание второго числа из первого.
- Умножение двух чисел.
- Деление с проверкой деления на ноль.
- Вычисление среднего арифметического списка чисел.
- Проверка корректности введённых чисел.

## 3. Требования

Для работы программы необходимы:

- Операционная система: Windows 11.
- Python: версия 3.
- Git - для клонирования репозитория.
- Сторонние библиотеки не требуются.

## 4. Установка

Для получения проекта необходимо:

1. Установить Python 3.
2. Установить Git.
3. Открыть терминал.
4. Выполнить команду клонирования репозитория:

   `git clone https://github.com/Mitzuki1007/python-calculator.git`

5. Перейти в папку проекта:

   `cd python-calculator`

## 5. Запуск программы

Для запуска калькулятора откройте терминал в корневой папке проекта и выполните:

```bash
python main.py
```

## 6. Примеры использования

### Пример 1. Сложение двух чисел

1. Пользователь запускает программу.
2. Выбирает пункт меню 1.
3. Вводит первое число 2.
4. Вводит второе число 3.

Ожидаемый результат: 5

### Пример 2. Вычисление среднего арифметического

1. Пользователь выбирает пункт меню 5.
2. Вводит числа 2 4 6.

Ожидаемый результат: 4.0

## 8. Тестирование

Чтобы запустить автоматические тесты, выполните данную команду в корневой папке проекта:

```bash
python -m unittest -v
```

При успешном выполнении все тесты должны завершиться результатом **OK**.
