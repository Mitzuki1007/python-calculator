# История изменений Python Calculator

## 1. Первоначальная версия программы

- Создана консольная программа-калькулятор на Python.
- Реализованы операции сложения, вычитания, умножения и деления.
- Добавлено вычисление среднего арифметического списка чисел.
- Реализовано текстовое меню для взаимодействия с пользователем.

## 2. Исправление ошибок и добавление тестов

- Добавлена проверка правильности введённых чисел.
- Реализована обработка деления на ноль.
- Добавлена проверка пустого списка при вычислении среднего арифметического.
- Реализована обработка неправильного пользовательского ввода.
- Создан файл `test_main.py` с автоматическими тестами.
- Исправлены несоответствия между названиями функций программы и тестов.

## 3. Улучшения, внесённые при работе с Git

- Исправлено название главного меню калькулятора.
- Улучшено сообщение при завершении работы программы.
- Добавлена справочная информация и отдельный пункт меню «Помощь».
- Улучшено сообщение при выборе несуществующего пункта меню.
- Созданы дополнительные ветки для независимой разработки функций.
- Выполнено слияние изменений через Pull Request.
- Создан учебный файл `conflict-demo.txt` для демонстрации конфликта слияния.
- Выполнено ручное разрешение конфликта между ветками.
